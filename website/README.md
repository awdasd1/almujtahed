# موقع المغني

مجلد موقع التعريف بالمغني وتحديثاته وتنزيلاته.

## السمة المثبتة

سمة الموقع نسخة طبق الأصل من قالب «المزخرف» المشغَّل في التطبيق
(فوق الأساس الرملي)، ثُبّتت نسخة افتراضية للموقع. مواصفاتها الكاملة
في `data/theme.json`، وصورة الخلفية في `assets/background.jpg`
(من خلفية التطبيق نفسها، بشفافية 8%). أي تغيير لاحق في قالب التطبيق
لا ينعكس هنا إلا بقرار — هذه النسخة مثبتة.

## التشغيل المحلي

```bash
cd website
python3 -m http.server 8765
# افتح http://localhost:8765
```

## تحديث البيانات

- **سجل الإصدارات و«ما الجديد»**: يُولَّد من `changes.md` في جذر المشروع:
  `python3 website/build_data.py`
- **إضافة ملف لأي قسم** (مشاريع/محادثات/مخطوطات/وكلاء/قراءة وأدوات/أنماط):
  1. ضع الملف في `website/files/<القسم>/`.
  2. أضف سطرًا في `website/data/catalog.json` تحت قسمه:

```json
{"key": "p1", "name": "اسم الملف", "desc": "وصفه",
 "file": "files/projects/p1.zip", "size": "2 MB",
 "date": "2026-11-25", "downloads": 0}
```

  `key` فريد لا يتكرر أبدًا (عليه تُبنى عدّادات التحميل).
- **نسختا التطبيق**: ضع `almoghni.exe` و`almoghni.dmg` في
  `website/files/downloads/` وحدّث `size` و`date` في `installers`
  داخل `catalog.json`. الزر يُعطَّل تلقائيًا ما دام الملف غائبًا.

## العدّادات

النسخة المحلية: عدد الزوار والتحميلات يُحسب في متصفح الزائر
(localStorage) فوق أرقام `downloads` الأساسية في الكتالوج — للتجربة
والاعتماد البصري. عند الرفع على الاستضافة تُستبدل بدالة خادمية صغيرة
تقرأ/تزيد ملف عدّاد، بلا تغيير في شكل الصفحة.
