# نشر موقع المغني على لينكس (VPS + Nginx)

الحزمة جاهزة؛ عند وصول بيانات الخادم تُنفَّذ الخطوات التالية بالترتيب:

1. تثبيت Nginx (و Certbot للشهادة) إن غابا.
2. نسخ محتوى `website/` (بلا `deploy/` و`build_data.py`) إلى
   `/var/www/almoghni/`، ونسختا التطبيق إلى `files/downloads/`.
3. نسخ `site_api.py` إلى `/opt/almoghni-site/` وتثبيت وحدة systemd
   وتمكينها، وإنشاء `/var/lib/almoghni-site/` بملكية www-data.
4. تفعيل `nginx-almoghni.conf` بعد استبدال النطاق، وفحص `nginx -t`.
5. توجيه DNS (سجل A) إلى الخادم ثم إصدار شهادة Let's Encrypt وتحويل
   HTTP إلى HTTPS.
6. ربط واجهة الموقع بالخدمة: رسائل النافذة تُرسَل إلى `/api/message`،
   والعدّادات تُقرأ من `/api/stats` (مع بقاء العدّ المحلي احتياطيًا).
7. اختبار حي: فتح الموقع، تنزيل نسخة، إرسال رسالة تجريبية، والتحقق من
   تسجيلها في `/var/lib/almoghni-site/messages.jsonl`.

ملاحظات أمان: الخدمة تستمع على 127.0.0.1 فقط خلف Nginx، وبيانات
الزوار خارج جذر الويب، ولا أسرار في المستودع أبدًا.
